# Kourovka Problem 21.89 — Partition Number Not Dividing Factorial

## Source statement

> 21.89. For n > 39, is it true that the number of conjugacy classes in the symmetric group Sn of degree n is never a divisor of the order of Sn ? In other words, is it true that, for n > 39, the number p(n) of integer partitions of n is never a divisor of n!? D. MacHale

## Why this is in the tractable 50

This is unusually attractive: the group theory collapses to the explicit divisibility question p(n) ∤ n!, allowing exact computation to locate the needed valuation obstruction and analytic number theory to finish the tail.

This is a falsifiable selection judgment: the first cycle should produce either a bounded search with meaningful coverage, a named reduction, or a concrete obstruction. Failure to do so is evidence to skip rather than extend.

## Proposed first attack

1. Formalize every hypothesis as an exact predicate and test it on hand-checked positive and negative examples.
2. Run the smallest complete family available, recording the exact library/version, object identifiers, and coverage bound.
3. Inspect the first near misses to conjecture a structural reduction; do not infer the universal statement from a clean finite range.
4. Seek a certificate independent of the discovery computation.

## What an answer would require

A proof that every n>39 has a prime-adic obstruction, with computation covering only the finite exceptional range. A positive computational pass alone is only necessary evidence unless exhaustive coverage of the mathematical target is proved.
