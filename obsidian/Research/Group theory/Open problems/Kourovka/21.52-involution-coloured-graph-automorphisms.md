# Kourovka Problem 21.52 — Involution Coloured Graph Automorphisms

## Source statement

> 21.52. Let L be a finite non-abelian simple group, and let D be a conjugacy class of involutions in L. Consider the complete graph Γ with vertex set D. Define an equivalence relation ∼ (graph coloring) on the set of edges as follows: (a, b) ∼ (c, d) if and only if |ab| = |cd|. An automorphism of the coloured graph Γ is a permutation τ ∈ SD such that (a, b) ∼ (aτ , bτ ) for every edge (a, b). Is it true that the automorphism group of Γ is a subgroup of Aut(L)? I. B. Gorshkov
