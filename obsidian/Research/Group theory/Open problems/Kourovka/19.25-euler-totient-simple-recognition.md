# Statement

Let (G) and (H) be finite groups of the same order such that
\[
\sum_{g\in G}\varphi(|g|)=\sum_{h\in H}\varphi(|h|),
\]
where (arphi) is Euler's totient function. Suppose that (G) is simple. Is (H) necessarily simple?

# Why selected

This is a finite, computable recognition question. For each finite simple group available through character- or permutation-group data, one can search groups of the same order and compare the exact totient sum. A counterexample is a finite certificate; a bounded positive screen can identify the first unresolved orders and useful invariants, while not being mistaken for a universal proof.

# Deliverables

Re-read the source statement, check current literature/status, implement an exact bounded search over available finite groups, and report either a concrete counterexample or a sharply delimited obstruction.
