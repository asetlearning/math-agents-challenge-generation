# Statement

An element (g) of a finite group (G) is vanishing if (chi(g)=0) for some irreducible complex character (chiinoperatorname{Irr}(G)). Must a finite group and a finite simple group be isomorphic if they have equal orders and the same set of orders of vanishing elements?

# Why selected

This is a finite, computationally testable recognition question. A counterexample consists of two explicit groups of equal order, one simple and one nonsimple, together with independently computed vanishing-element order sets. GAP's character-table library can screen available finite groups; a positive search result is a directly checkable finite certificate. A negative bounded screen is only evidence and must not be promoted to a universal proof.

# Deliverables

Re-read the source statement, perform a staleness/literature check, implement an exact bounded character-table screen, and record whether a concrete pair or a credible proof obstruction emerges.
