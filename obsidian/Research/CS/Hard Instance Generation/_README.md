## Research/CS/Hard Instance Generation/

**What belongs here:** papers whose primary contribution is *generating* or *characterising* hard problem instances with a known answer, outside group theory: planted / quietly planted random CSP and k-SAT ensembles, learned or adversarial instance samplers, teacher-generated task curricula. Plus the cross-domain synthesis for `#project/challenge-gen`.

**Does not belong here:** group-theoretic instance generation (trivial words, AC presentations) → `Research/Group theory/` (Word Problem/, Open problems/Free groups/, Burnside groups/); RL for math → `Research/AI in Math/RL/`.

**Filename convention:** `<first-author>-<year>-<slug>.md`, or the arXiv ID.
