1. **Frozen artifacts.** SHA-256 verifies that the claimant script and raw output

2. **Table semantics and identity.** A separately written GAP script queries only
   `CharacterTable("3.U3(5)")`, checks ordinary/perfect/quasisimple status,
   construction text, order/centre/quotient data, class-size and degree-square
   sums, exact cyclotomic storage, and all 1,600 row scalar products. This verifies
   the installed CTblLib object's semantics, not CTblLib from first principles.
3. **All cells.** The fresh scan is class-major and tests exact quotient

   arithmetic, and compares labels, degrees, orders, exact canonical cyclotomic

4. **Bounded meaning.** Both the submitted record and the fresh manifest prohibit
   neighbouring tables or catalogue expansion. A pass therefore excludes only this
   stored ordinary table as a source of a counterexample.

## Hand reconstruction

The order formula and centre are

```text
|SU_3(5)| = 5^3(5^2-1)(5^3+1) = 378000
378000 = 2^4 * 3^3 * 5^3 * 7
|Z(SU_3(5))| = gcd(3,5+1) = 3
```

The class sizes group to

```text
3 + 3*525 + 10500 + 3*15750 + 3*504
  + 9*5040 + 3*10500 + 6*18000 + 6*15750 + 3*12600
= 378000.
```

The degree multiplicities are

```text
1^1, 20^1, 21^5, 28^3, 48^6, 84^3, 105^5,
125^1, 126^9, 144^6,
```

and their square sum is

```text
1 + 400 + 5*441 + 3*784 + 6*2304 + 3*7056
  + 5*11025 + 15625 + 9*15876 + 6*20736
= 378000.
```

Primewise comparison of the nine nontrivial degree types with the 14 class-order
types shows exactly 423 coordinates where `degree * class_order` does not divide
378000: respectively 6, 30, 36, 108, 36, 30, 15, 54, and 108 for degrees
20, 21, 28, 48, 84, 105, 125, 126, and 144. The fresh exact table scan finds zero
at every one of these dangerous coordinates. The other 1,177 coordinates satisfy
the integer divisibility independently of their character value.

## Why this verdict

The threshold for `replicated` is met by two independent programs: the claimant's
row-major remainder computation and the Validator's class-major exact-quotient
computation, followed by a frozen coordinatewise comparison. `proven` is not
appropriate because this is a computation in one library table, not a line-by-line
proof of the universal statement or an independent reconstruction of the table
from a group presentation.

## What is NOT established

- The universal implication for all finite groups is not proved or refuted.
- No group or table other than `3.U3(5)` was checked by this verification.
- The unitary prime-three family is not settled.
- CTblLib/ATLAS data are not reconstructed from first principles; the result is
  conditional on the correctness of the stored ordinary table.
- This does not license a next table, catalogue search, or scope closure.
