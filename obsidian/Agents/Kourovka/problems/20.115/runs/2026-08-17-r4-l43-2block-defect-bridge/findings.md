# Finite `L4(3)` prime-2 block-defect bridge

## Outcome

`PARTIAL_RESULT`, pending independent review. For the centerless simple group
$L=\operatorname{PSL}_4(3)$ and $p=2$, every ordinary 2-block $B$ satisfies

\[
\exp(D_B)\le 2^{\operatorname{def}_2(\chi)}
 = \left(\frac{|L|}{\chi(1)}\right)_2
 \qquad(\chi\in\operatorname{Irr}(B)).
\]

Thus every 2-block satisfies Condition $(\ddagger)$; because $Z(L)=1$, this is
also Condition $(\ddagger^\star)$. The exact Proposition 3.2 consequence is stated
below. This is a finite prime-2 bridge, not a proof of the universal Kourovka
statement.

### Block 2

Take $D_2=\langle x\rangle$, where

```text
x=(1,11,12,13)(2,14,20,17)(3,35,34,39)(4,29,27,25)(5,37,28,19)(6,31,21,38)(7,16,32,24)(8,30,33,18)(9,36,22,23)(10,15,26,40).
```

This is an explicit block-2 defect group, not merely a subgroup of the correct
order:

1. The table has a unique order-4 class with centralizer order $1440$, namely
   class `4a`. The displayed $x$ has order $4$ and centralizer order $1440$
   in the fixed `PSL(4,3)`, so it represents `4a`.
2. Ordinary row 16 lies in block 2 and has the exact value
   $\chi_{16}(4a)=16\ne0$.
3. Theorem 3.5 of Malle--Navarro--Tiep says that a $p$-element lies in a
   conjugate of a block defect group iff some ordinary character in that block is
   nonzero on it. Hence $x$ lies in a conjugate of a block-2 defect group.
4. Block 2 has defect 2, so its defect groups have order $4$. Since $o(x)=4$,
   that conjugate equals $\langle x\rangle$.

Therefore $|D_2|=4$ and $\exp(D_2)=4$.

## Exact Proposition 3.2 implication

Malle--Navarro--Tiep, arXiv:2605.04513v1, Proposition 3.2 states: if $H$ is as in
Conjecture 2.3, $L=[H,H]$, and all $p$-blocks of $L$ satisfy
$(\ddagger^\star)$, then $(\ddagger^\star)$ holds at $p$ for all
$\chi\in\operatorname{Irr}(H)$ whose restriction to $L$ is irreducible, and
Conjecture 2.3 holds for $H$ at $p$.

Apply this with $p=2$ and $L=\operatorname{PSL}_4(3)$. Since $Z(L)=1$, the
verified $(\ddagger)$ inequalities are exactly $(\ddagger^\star)$. Therefore,
for every intended triple $(H,h,\chi)$ satisfying $(*)$ with
$[H,H]=L$,

\[
o(hZ(H))_2\mid
\left(\frac{|H:Z(H)|}{\chi(1)}\right)_2.
\]

Indeed, in such a triple $\chi(h)\ne0$ implies that $\chi|_L$ is irreducible,
as recalled in the proposition. Here $Z(H)=Z(L)=1$, so the displayed conclusion
is equivalently

\[
o(h)_2\mid\left(\frac{|H|}{\chi(1)}\right)_2.
\]

This is Condition (1.1) at the prime 2 for all nearly-simple triples with derived
subgroup `L4(3)`.

## What this does not establish

- It does not prove Wilde's conjecture for every finite group or at every prime.
- It gives only the prime-2 part of Condition (1.1) for nearly-simple triples whose
  derived subgroup is exactly centerless `L4(3)`.
- It does not assert that Condition $(\ddagger)$ is necessary; only its sufficient
  implication through Proposition 3.2 is used.
- A failure of this block inequality elsewhere would not be a counterexample to the
  source conjecture.
- Independent Validator reproduction remains required before this finite lemma is
  promoted above `status/conjectured`.
