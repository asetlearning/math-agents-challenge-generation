# Verification — Kourovka 21.31 — diagram restriction groups

## The claim

For the conditional overgroup extension class represented by (z\in Z(K)[2]), let (H=q^{-1}(P)\cong K\times P), where (P=C_7:C_3<T=GL_3(2)). The restriction image of compatible marked-diagram automorphisms is

\[
A_i\cong Stab_{Aut(K)}(z)\times Aut(P),
\]

acting factorwise on (K\times P). The resulting nine orders are

```text
K=[12,1]: split 504, nonsplit 504
K=[12,2]: split 168, nonsplit 168
K=[12,3]: split 1008
K=[12,4]: split 504, nonsplit 504
K=[12,5]: split 504, nonsplit 168
```

## Target vs witness

These groups are conditional diagram data for hypothetical order 2016, not regular embeddings or target holomorphs. Witness equals target is false, so the overall verdict remains `status/conjectured`.

## Exhaustion proof

The extension class lies in

\[
H^2(T,Z(K))\cong Hom(M(T),Z(K))\cong Z(K)[2].
\]

A pair ((a,\tau)\in Aut(K)\times Aut(T)) lifts to an automorphism of the extension exactly when naturality preserves the class:

\[
a_*(e_z)=\tau^*(e_z).
\]

The multiplier (M(T)=C_2) has trivial automorphism group, so every automorphism tau acts trivially on the parameter and the condition is exactly (a(z)=z). The kernel of the map from extension automorphisms to compatible pairs is

\[
H^1(T,Z(K))=Hom(T,Z(K))=0
\]

because (T) is perfect. Hence every compatible pair has one lift and no global derivation/twist factor is omitted.

After fixing (P), the quotient factor is (Aut(T)_P). The independent computation gives

```text
|Aut(T)_P| = 42
restriction image in Aut(P) = 42
restriction kernel = 1
|Aut(P)| = 42
```

so restriction identifies (Aut(T)_P\cong Aut(P)).

For split (G=K\times T), all lifts act factorwise because `Hom(T,Z(K))=0`. For a nonsplit Schur pushout, the only cover ambiguity on the preimage of (P) is a homomorphism (P\to C_2); this is zero because (P_{ab}\cong C_3). Thus the global unique lift restricts factorwise on the chosen (H=K\times P). Although some (Z(K)) contain 3-torsion and the abstract split central extension over (P) can have other complements, those do not arise as restrictions of global twists: the global `H^1(T,Z(K))` kernel is zero. Hence there is no missing cross-homomorphism factor.

The two factor actions commute and intersect trivially because one fixes (P) pointwise and the other fixes (K) pointwise. Therefore their generated group is the direct product claimed.

## Stabilizers and the exceptional case

For `K=[12,1]`, `[12,2]`, and `[12,4]`, the central involution is unique and every automorphism fixes it. `A4` has trivial center and only the split class. For `K=[12,5]=C6 x C2`, the three nonidentity elements of (Z(K)[2]) form one orbit under `Aut(K)` of order 12, so the stabilizer of a chosen nonsplit parameter has order (12/3=4). This gives (4\cdot42=168), while its split class uses all of `Aut(K)` and has order 504.

## Concrete generator audit

The claimant's script builds factorwise maps and checks individual bijectivity, but prints the product order rather than computing the group generated by those maps. The independent script closes that gap: on each concrete direct product (H=K\times P), it constructs the same two factor types, forms their generated mapping group, computes its actual order, and checks every stored generator is bijective.

All nine generated orders equal the theoretical product orders. Generator counts also reproduce the claimant's table: `6,6,5,5,7,6,6,8,5` in the displayed class order.

## Circularity check

The independent script recomputes `Aut(T)_P`, its restriction image/kernel, involution stabilizers, and actual generated mapping-group orders. It does not import the claimant's script or hard-code the nine expected orders as results.
