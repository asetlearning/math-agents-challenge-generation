# Outcome: STRATEGY_EXHAUSTED

Scope: `21.137/odd-prime-exponent-p2`, assignment revision 2.

Named strategy: `TRIPLE-ROOT-ASSOCIATOR-COHERENCE`.

## Exact method-failure certificate

For actual values `A=a^p`, `B=b^p`, `C=c^p`, choose arbitrary roots

```text
u^p=AB,  v^p=BC,  r^p=(AB)C,  s^p=A(BC).
```

Set

```text
k1=ab u^-1,  k2=u c r^-1,  k3=bc v^-1,  k4=a v s^-1.
```

Then, exactly in the group,

```text
(k1 k2)^-1 (a k3 a^-1) k4 = r s^-1.             (T)
```

The intermediate-root freedoms cancel. Since `(AB)C=A(BC)`, `r` and `s` are in
the same root fibre. Replacing `s` by `r` is a permitted gauge change and kills
the right side. If one uses a single value section, that replacement is already
forced and `(T)` is the universal factor-set cocycle identity coming from group
associativity. Independent local sections merely restore the arbitrary transition
`r s^-1`.

For completeness, if `t'=tq`, then

```text
(tq)^p=t^p q^(t^(p-1)) ... q^t q;
```

thus equality of the two power values is exactly the relative norm-one condition
for the allowed root change. Projecting `(T)` to any Zassenhaus layer shows that
the alleged first associator residual is the terminal lift difference. Full
root/section/lift gauge removes it in every degree.

## Formal nonzero-bracket jet

For every odd `p`, start with `P0=UT_3(F_p) x C_p` and noncommuting standard
values `A,B`. Attach cyclic order-`p^2` leaf groups by amalgamating each leaf's
order-`p` subgroup onto the cyclic subgroup generated by each of
`A,B,C,AB,BC,ABC`, with two leaves over `ABC`. Vertex-group injectivity preserves
`[A,B]!=1`, while all four root equations and their ambiguity rows hold. This is
an exact local formal model of the attempted calculation.

It is deliberately **not** a target candidate: the amalgam is infinite, lacks
global exponent `p^2`, and does not assert that its complete actual power set is a
subgroup. Its sole role is to certify that the local four-root associativity rows
do not eliminate a nonzero bracket.

## Scope of the negative result

The calculation exhausts the named associator comparison only. It does not answer
whether the actual `p`-power subgroup in a finite exponent-`p^2` `p`-group is
abelian. A future route must use genuinely global information—such as finite fibre
counts/orbits or a minimum-counterexample normal-subgroup argument—not another
choice of local product-root section.
