## Hand audit before implementation

Timestamp: `2026-08-17T03:20:30Z`; cumulative active minute `165`.

1. For any associative nilpotent algebra element `x` over `F_3`, ordinary binomial expansion is valid for `1+x` because `1` commutes with `x`: `(1+x)^3=1+3x+3x^2+x^3=1+x^3`. Iterating gives `(1+x)^9=1+x^9`. In strictly upper-triangular `7 x 7` matrices, every product of seven elements is zero, so `x^7=0` and therefore `x^9=0`.
2. `S=E12+E23+E34+E45+E56+E67` has `S^3=E14+E25+E36+E47`, which is nonzero. Hence `1+S` has nontrivial cube and trivial ninth power, so its order is exactly `9`; combined with the preceding upper bound, `exp(1+J_tau)=9` for every row.
3. Every group element of `1+J_tau` has a unique form `1+x`, and its cube is `1+x^3`. Thus `1+X_tau`, for the exhaustively enumerated set `X_tau={x^3:x in J_tau}`, is exactly the actual cube-value set, not merely the subgroup it generates.
4. Under `u circle v=u+v+uv`, `(1+u)(1+v)=1+(u circle v)`. Therefore the subgroup generated by `1+X_tau` corresponds exactly to the circle subgroup `K_tau=<X_tau>_circle`. Since `X_tau` contains `0` and is inverse-stable as an actual power-value set (`(g^3)^{-1}=(g^{-1})^3`), equality of finite cardinalities `|K_tau|=|X_tau|` is equivalent to actual-value-set subgroup closure.
5. Writing `T=sum_i tau_i E_{i,i+1}`, direct path multiplication gives `T^3=sum_{i=1}^4 tau_i tau_{i+1} tau_{i+2} E_{i,i+3}`. Only the path `E14 E47=E17` contributes to `S^3T^3`, with coefficient `tau_4 tau_5 tau_6`; only the path `E14 E47=E17` contributes to `T^3S^3`, with coefficient `tau_1 tau_2 tau_3`. Their difference is `(tau_4 tau_5 tau_6-tau_1 tau_2 tau_3)E17`. The frozen endpoint inequality therefore makes two actual cubes noncommuting.
6. Grade strictly upper-triangular matrices by superdiagonal. If `x=v+h` with degree-one part `v` and `h` of degree at least two, then the degree-three component of `x^3` is exactly `v^3`. Products of two cube values start in degree at least six. Hence circle closure of `X_tau` forces additive closure of `C_tau={v^3:v in span_F3{S,T_tau}}`; a displayed pair `v,w` with `v^3+w^3` absent from `C_tau` is a sound rejection certificate, but a pass is only a prefilter.
