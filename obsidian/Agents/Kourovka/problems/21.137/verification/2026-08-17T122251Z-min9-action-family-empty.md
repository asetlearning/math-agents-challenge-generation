## Equality consequences reconstructed from the inherited rows

### The kernel P

Write `|P|=3^m`.  The inherited index bound gives

```text
log_3 |H| >= m + m-floor((m-1)/3)
             = 2m-floor((m-1)/3).
```

At `m=5` the right side is 9; at `m=6` it is already 11 and it then increases.
Thus order `3^9` forces

```text
|P|=3^5,                  |H:P|=3^4.
```

The inherited flag says `dim Z(P)>=3`.  Since `P` is nonabelian of class two,
the alternating commutator form on `P/Z(P)` is nonzero, so that quotient has
positive even dimension.  Total dimension five therefore forces

```text
dim Z(P)=3,               dim P/Z(P)=2.
```

The form on the two-space is nondegenerate: its radical would lift into the full
centre.  Splitting the three-dimensional centre into the derived line and a
central two-space yields

```text
P ~= H_3(3) x C3^2.
```

This deduction is valid from the inherited structural rows; it does not prove
those rows.

### The quotient R

Because every actual cube lies in `P`, `R=H/P` has exponent 3 and order `3^4`.
Put `d=dim R/R'`; here `Phi(R)=R'`.

- `d=4` gives `R'=1`, hence `R=C3^4`.
- `d=1` would make `R` cyclic, impossible at order 81 and exponent 3.
- `d=2` is impossible because a two-generated exponent-3 group has class at
  most two, one basic central commutator, and order at most 27.
- `d=3` gives `|R'|=3`.  A nontrivial `gamma_3(R)` would equal `R'` and make the
  lower central series stabilize, so `R` has class two.  The nonzero alternating
  form on the three-space `R/R'` has rank two and a one-dimensional radical,
  giving `R=H_3(3)xC3`.

Thus the displayed two quotient types are complete.

## Completeness of the action-image predicates

Every outer action image `U` is a quotient of `R`.

- For `R=C3^4`, every nontrivial image is elementary abelian `C3^d`,
  `1<=d<=4`.  This is exactly `IsElementaryImage(U,4)` in the script.
- For `R=H_3(3)xC3`, an abelian image factors through `R/R'=C3^3`, giving
  `C3^d`, `1<=d<=3`.  If an image is nonabelian, its kernel does not contain
  `R'`.  Any noncentral normal kernel would contain `R'`, so the kernel is either
  trivial or a central line disjoint from `R'`.  The image is consequently
  `H_3(3)xC3` of order 81 or `H_3(3)` of order 27.  These are exactly the three
  predicates used for the nonabelian quotient.

The trivial image can be omitted because it contains no regular `J3` element and
fails the next necessary gate.

On the characteristic three-space `Z(P)=C+W`, an eligible 3-image has common
fixed line `C` and contains a regular `J3`.  After a basis choice it lies in
`UT_3(3)`.  If the image is abelian, it lies in the unipotent centralizer of a
regular block, whose 3-part is `C3^2`; the possibilities are the regular cyclic
`C3` and that full `C3^2`.  A nonabelian central image has order 27 and is the
full `UT_3(3)`.  Hence the script's three central branches are exhaustive.
The explicit `UNEXPECTED_ELIGIBLE_BRANCH` hard error makes any violation visible.

## Automorphism, inner, outer, and Sylow reconstruction

Write the Lie algebra of `P` as `V+C+W`, with dimensions `2+1+2` and
`[v,v']=omega(v,v')c`.  Every automorphism has the unique block form

```text
[ g          0       0 ]
[ tau_C   det(g)   lambda ]
[ tau_W      0       h ]
```

where `g,h in GL_2(3)`, `lambda:W->C`, `tau_C:V->C`, and `tau_W:V->W`.
The form follows because the centre and derived line are characteristic; the
factor `det(g)` is forced by the bracket.  Conversely every displayed matrix
preserves the bracket and is invertible.

The independent parameter count is

```text
|Aut(P)| = 48^2 * 3^(2+2+4) = 15116544.
```

Inner automorphisms are precisely the two-dimensional `tau_C` shears, because
the symplectic form identifies `V` with `V*`.  Therefore

```text
|Inn(P)| = 3^2 = 9,
|Out(P)| = 48^2 * 3^6 = 1679616,
|Syl_3 Out(P)| = 3^(2+6) = 3^8 = 6561.
```

The script generates exactly these blocks, checks bracket preservation on every
generator, checks normality of the inner subgroup, forms the exact quotient, and
checks all four orders before any subgroup enumeration.  The frozen output agrees
with every hand count.

Every 3-subgroup of `Out(P)` is conjugate into the chosen Sylow subgroup `S`.
Consequently all `S`-conjugacy classes of subgroups form an overcomplete set of
representatives for full-outer conjugacy classes.  Failure of every retained
`S`-class is enough; full-outer fusion need not be completed.  The statement that
GAP's `ConjugacyClassesSubgroups(S)` returned a complete list of 17,409 classes is
computational evidence from the claimant's single run, not an independently
rerun enumeration in this audit.

## Capacity derived from the actual cube-value set

This is the key bridge which was only inherited in the preceding histogram note.
It can be reconstructed directly.

Let `theta:R->Out(P)` have image `U`.  Every `u in U` has exactly

```text
k=|ker theta|=81/|U|
```

quotient elements over it.  Right conjugation by an element in one quotient
coset has outer class `u^-1`; as the kernel coordinate in `P` varies, its actions
run through all nine inner lifts over `u^-1`.

There are eight nonzero labels in `V=P/Z(P)`.  Each label has a fibre of size
`|Z(P)|=27`.  Since the *actual* cube-value set is assumed equal to `P`, every
one of these `8*27=216` noncentral elements must occur as a cube.  This is why
there are eight demand nodes of capacity 27; generation of `P` would not suffice.

Fix one quotient coset and one inner lift

```text
N = [ G      0    0 ]
    [ alpha  0  lambda ]
    [ T      0    H ].
```

For an admitted nonzero label `v`, the preceding independent block audit gives
`Fix(I+N)=<C,a>` with projection `<v>`.  Holding the lift fixed, possible cube
values with projection `v` form at most the three-point affine `C`-line
`a+C`.  This proves the edge bound of three central values per fixed lift.

There is a second, stronger overlap bound across the nine lifts.  For a fixed
label `v`, the fixed equations are

```text
Gv=0,
Tv+Hw=0,
alpha(v)+lambda(w)=0.
```

The middle equation has solution set `w_0+ker(H)`.  Central regularity gives
`dim ker(H)=1` and makes `lambda` nonzero on that line.  As `alpha` ranges through
all nine rows in `V*`, only the scalar `alpha(v)` matters; it takes three values.
Thus at most three `W`-coordinates occur.  Each permits at most the three free
`C`-coordinates, so an entire quotient coset supplies at most nine distinct
noncentral cube values.  This proves the source bound, rather than assuming it.

For a fixed outer `u` and label `v`, if `n_u(v)` of its nine inner lifts pass,
the `k` quotient cosets can supply at most `3k n_u(v)` values to that label, while
their total supply is at most `9k`.  The exact necessary network is therefore

```text
source -> u:       capacity 9k,
u -> v:            capacity 3k n_u(v),
v -> sink:         capacity 27.
```

Overlaps of actual cube values are ignored, so this is an upper bound favorable
to existence.  If even this network has flow below 216, no factor system or
epimorphism can restore actual-set surjectivity.

The preceding independent nine-lift calculation proves
`n_u(v) in {0,9}`, with at most one nonzero label per `u`.  If `m_v` counts the
outer elements assigned to `v`, the network therefore collapses to

```text
maxflow = sum_{v != 0} min(27,9k*m_v).
```

This independently validates the precise source, edge, and demand capacities
used at script lines 242--252.

## Conjugacy invariance

Let `beta in Out(P)` and conjugate `U` by `beta`.  Any automorphism representative
of `beta` bijects:

- elements `u` with elements of `U^beta`;
- the nine inner lifts over `u^-1` with the nine inner lifts over the conjugate;
- nonzero labels in `V` through the induced invertible linear map;
- fixed spaces, inner-cube maps, and Jordan ranks through conjugation.

Thus the profile is changed only by permutations of its outer-element rows and
eight label columns.  The value of `k` and all equal demand capacities remain the
same, so max flow is invariant.  Hence a failed prefusion representative has no
full-outer conjugate which can pass.  With zero prefusion survivors, epimorphism
orbits and full-outer fusion are genuinely vacuous.
