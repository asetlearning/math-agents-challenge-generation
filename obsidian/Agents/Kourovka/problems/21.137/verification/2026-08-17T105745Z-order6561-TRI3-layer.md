## Hand audit

### 1. Quotienting by every central `C3` forces a cyclic centre

Let `A` have order `3^8`, exponent 9, and actual cubes `s=x^3`, `t=y^3` with

`c=[s,t] != 1`, using `[u,v]=u^-1 v^-1 u v`.

For every `N<=Z(A)` of order 3, the quotient `A/N` has order `3^7` and exponent 3 or 9. If its exponent is 3, both cube images are trivial. If its exponent is 9, the complete order-`3^7` audit below shows that all actual cube values commute. Hence `c in N` for every such `N`.

A nontrivial finite 3-group has a nontrivial centre, so at least one `N` exists. Membership in it proves that `c` is central of exact order 3. Any two central order-3 subgroups both contain the nonidentity element `c`, hence are equal. Thus `Z(A)` has a unique order-3 subgroup.

For a finite abelian 3-group, the dimension of the subgroup killed by 3 equals the number of invariant factors. Uniqueness therefore makes `Z(A)` cyclic. Since its exponent divides 9,

`Z(A) ~= C3` or `C9`.

### 2. TRI3 strengthens the centre to exactly `C3`

The TRI3 datum contains a central subgroup `C` of order 3, so it is the unique central order-3 subgroup just found. If `Z(A)=<z> ~= C9`, then `C=<z^3>`. For every occupied `C`-fibre, choose `x^3` in it. Centrality gives

`(xz^k)^3=x^3 z^(3k)` for `k=0,1,2`.

These are all three distinct points of `x^3C`. Thus every occupied fibre is full, independently of section translation. TRI3 requires every occupied fibre to have size 2 or 3 and at least one to have size 2. Contradiction. Hence, for a TRI3 seed,

`Z(A)=C~=C3`.

This argument is specific to TRI3. The direct-counterexample proof below retains the alternative cyclic centre `C9` and does not silently import the two-point-fibre hypothesis.

### 3. Projective closure is enough in the reviewed class-five identity

Let `S={x^3:x in A}` and assume only the TRI3 projective condition

`T=SC/C=Pow_3(A/C) <= A/C`.

The set of actual cubes in a quotient is conjugacy-invariant. Since `T` is also a subgroup, it is normal. Its full preimage

`U=SC`

is therefore a normal subgroup of `A`. Every `u in U` has the form `u=x^3d` with `d in C`. Since `C` is central of order 3 and `A` has exponent 9,

`u^3=(x^3d)^3=x^9d^3=1`.

Thus `U` has exponent 3 although `S` itself need not be closed.

The four terminal elements in the previously reviewed class-five identity all lie in `U`, using only operations valid in this normal subgroup:

- `[y,x^3]=(x^-3)^y x^3 in U`; after removing the actual cubes `c^3,a^3`, one gets `T_A in U`, and normality gives `S_A=[T_A,y] in U`.
- `[x,y^3]=(y^-3)^x y^3 in U`; after removing the actual cubes `q_1^3,q_2^3`, one gets `T_B in U`, and normality gives `Q=[T_B,x] in U`.

The checked integral identity is

`[x^3,y^3]=c^-9 a^-9 b^-9 beta^-9 delta^54 epsilon^27 T_A^-3 S_A^-3 T_B^3 Q^3`.

Exponent 9 kills the first six factors, and exponent 3 in `U` kills the four terminal powers. Therefore `[x^3,y^3]=1` for all `x,y` whenever `cl(A)<=5`. A TRI3 seed with noncommuting cubes must have class at least 6.

An order-`3^8` group has class at most 7, so only classes 6 and 7 remain.

### 4. Exact quotient-base filter for TRI3 seeds

For a TRI3 seed put `Q=A/C`. The quotient has order `3^7`. Its exponent divides 9. If its exponent were 3, every cube of `A` would lie in the central subgroup `C`, contradicting the required noncommuting cube pair. Hence `exp(Q)=9`.

Moreover,

`Pow_3(Q)=SC/C=T`

is a nontrivial subgroup. If `d=cl(A)` is 6 or 7, then the last lower-central term `gamma_d(A)` is nontrivial and lies in `Z(A)=C`; hence `gamma_d(A)=C`. The preceding term cannot lie in `C`, because then it would be central and `gamma_d(A)=[gamma_(d-1)(A),A]` would be trivial. Therefore

`cl(A/C)=d-1`,

so the quotient class is exactly 5 or 6. Every TRI3 seed must consequently have a quotient base satisfying exactly these four gates:

1. order `3^7` and exponent 9;
2. class 5 or 6;
3. nontrivial complete actual-cube set;
4. that complete set is a subgroup.

Because the complete base filter is empty, no central extension or descendant enumeration is needed to exclude the order-`3^8` TRI3 seed family.

### 5. The stronger direct order floor uses a different class-drop lemma

Let `G` itself be a direct counterexample of order `3^8`: exponent 9, complete actual-cube set `P` a subgroup, and `P` nonabelian. The cyclic-centre argument applies because `P` contains a noncommuting pair, but it yields only `Z(G)~=C3` or `C9`. Let `N` be its unique central subgroup of order 3.

The reviewed full-closure theorem gives `cl(G)=d>=6`; hence `d` is 6 or 7. For any central `N` of order 3,

`gamma_i(G/N)=gamma_i(G)N/N`.

If `gamma_d(G)` is not contained in `N`, then `cl(G/N)=d`. If it is contained in `N`, then the quotient class is exactly `d-1`: it cannot drop farther, because `gamma_(d-1)(G)<=N<=Z(G)` would imply `gamma_d(G)=1`. Thus a central quotient drops class by zero or one, not automatically by one.

For `d=6`, the quotient class is 5 or 6. For `d=7`, an order-`3^7` group cannot have class 7, so the quotient class is 6. In every case it lies in the frozen class-5/6 filter.

If `exp(G/N)=3`, then every cube of `G` lies in central `N`, contrary to nonabelian `P`. Hence `exp(G/N)=9`. The image

`Pow_3(G/N)=PN/N`

is a nontrivial subgroup, again yielding an eligible filtered base. There is none. Therefore no direct counterexample has order `3^8`.

For a hypothetical smaller direct counterexample `K` of order `3^n`, `n<7`, the group

`K x C3^(7-n)`

has order `3^7`, exponent 9, and complete actual-cube set `Pow_3(K) x {1}`, still a nonabelian subgroup. This contradicts the complete order-`3^7` scan. Together with the direct order-`3^8` exclusion, any direct `p=3` counterexample has order at least `3^9`.
