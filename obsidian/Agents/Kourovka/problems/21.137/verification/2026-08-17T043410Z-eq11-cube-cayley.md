## Exponent, independently

Every `J_tau` is contained in the algebra of strict upper-triangular `7 x 7` matrices, so every product of seven elements of `J_tau` is zero. In particular `x^7=0`, hence `x^9=0`, for each `x in J_tau`. Since powers of the single element `x` commute with one another, characteristic 3 gives

`(1+x)^3=1+x^3` and `(1+x)^9=1+x^9=1`.

Thus the group exponent divides 9. But `S in J_tau` for every row and

`S^3=E_14+E_25+E_36+E_47 != 0`.

Consequently `(1+S)^3 != 1`, while `(1+S)^9=1`, so `1+S` has order 9. Every saved group has exponent exactly `9=3^2`.

## Actual-set reconstruction

The map `x -> 1+x` is a bijection from `J_tau` to `G_tau`, and

`(1+x)^3=1+x^3`.

Accordingly the actual group cube set is exactly `1+V_tau`, where `V_tau={x^3:x in J_tau}`. The independent checker generated every basis-coordinate code from `0` through `3^dim J_tau-1`, reconstructed its matrix from the independently generated RREF basis, evaluated the length-three path formula for `x^3`, and compared all three columns of every compressed cube-map row. It also reconstructed the first root of each value and compared the complete actual-value/root manifest. All eleven certificates passed.

## The three actual-set/Cayley equalities

For each scalar row `tau=(c,c,c,c,c,c)`, `T_tau=cS`, so

`J_tau=span_F3{S,S^2,...,S^6}`.

This algebra is commutative. If `x=sum_{i=1}^6 a_i S^i`, the characteristic-3 Frobenius calculation inside this commutative algebra gives

`x^3=a_1 S^3+a_2 S^6`.

Hence the actual cube-coordinate set is the nine-element plane `V=span_F3{S^3,S^6}`. Under the circle law,

`(aS^3+bS^6) circle (cS^3+dS^6)=(a+c)S^3+(b+d+ac)S^6`,

so it is closed and commutative.

The artifact's Cayley logic is also valid independently of this hand derivation. Its two generator values lie in the actual set. The independently generated finite monoid has exactly nine states, equal as an actual set of matrix codes to all nine cube values. A finite submonoid of a group is a subgroup, so set equality proves actual-set subgroup closure. The two generators commute, hence the subgroup they generate is abelian. As a redundant hostile check, all `9*10/2=45` unordered pairs of actual values were multiplied in both orders and agreed for each scalar row.
