# EQ11-CUBE-CAYLEY

## Scope lock

Target: `21.137/odd-prime-exponent-p2`, revision `2`: for an odd prime `p`, a finite same-`p` group `G` of exponent exactly `p^2`, and the actual value set `P={g^p:g in G}`, decide whether the hypothesis that `P` is a subgroup forces `P` to be abelian. The general powerfulness clause, every `p=2` case, and every odd-prime group of exponent other than exactly `p^2` stay excluded.

Cited internal scope source: `Agents/Kourovka/scopes/21.137-odd-prime-exponent-p2.json`.

## Obstruction

Cited internal Validator finding: `ALG3-UT7-CUBE-IMAGE/F_12` exhausted only the ten low-dimensional rows with unequal endpoint products. Eleven rows with `dim J_tau<=12` and equal endpoint products are outside that frozen family. Endpoint equality says only that the designated values `1+S^3` and `1+T_tau^3` commute; it says nothing about a different pair in the full actual cube set. See `Agents/Kourovka/problems/21.137/verification/2026-08-17T035316Z-alg3-ut7-family-exhaustion.md`.

The target-facing obstruction is therefore simultaneous and exact: find a different noncommuting pair of actual cubes and establish closure of the whole actual cube set. A leading-layer pass, a generated subgroup without set equality, or a raw pair is insufficient.

## The one proposed experiment

**Direction:** counterexample.

**Frozen family:**

`E_12={tau in F_3^6 : dim J_tau<=12 and tau_1 tau_2 tau_3=tau_4 tau_5 tau_6}`,

where `J_tau=<S,T_tau>` and `G_tau=1+J_tau` are exactly as in the cited family report. That report counts `|E_12|=11`. Do not add a generator, raise the cutoff, or include any unequal-endpoint row.

**New representation:** replace the old endpoint scalar and degree-three projection by the complete, hash-indexed actual-value Cayley subset. In a fixed basis of `J_tau`, represent `1+u` by the coordinate vector `u`, with exact group law

`u circle v = u+v+uv`.

Enumerate every `x in J_tau` and form the actual set

`V_tau={x^3:x in J_tau}`,

retaining one canonical preimage for every value. Cited internal Validator finding: in this algebra-group model `(1+x)^3=1+x^3`; the same report also gives finiteness at `p=3` and the exact-exponent-`9` check from `S^3!=0` and upper-triangular nilpotence.

**Exact observable:** scan `V_tau` lexicographically while building a positive-generator Cayley BFS.

1. Start with `B=[]` and the identity state. When a scanned `v in V_tau` is not in the current generated set, append `v` to `B` and grow the Cayley BFS by right multiplication with the members of `B`.
2. Maintain the invariant that every expanded state lies in `V_tau`. If a first transition `u circle b=w` leaves `V_tau`, save `(u,b,w)` and canonical cube roots of `u,b`. This is a direct actual-value closure defect, since `u,b in V_tau` and `w notin V_tau`.
3. If all of `V_tau` is absorbed with no boundary transition, the enumerated actual set and the BFS-generated group are the same explicit finite set. Record that full set equality, not merely the abstract subgroup generated by cubes.
4. Only after that equality, test the at-most-`dim J_tau` members of `B` pairwise. Save the first `b_i b_j != b_j b_i`, together with their retained cube roots. If every pair in `B` commutes, the group generated by `B` is abelian.

Define the two deterministic observables to be the first closure-boundary triple (or `NONE`) and, conditional on `NONE`, the first noncommuting generator pair (or `NONE`). This is genuinely different from the killed endpoint-pair/leading-layer observable and directly tests the full actual-value set.

General knowledge, unverified: in a finite group, the explicit equality `V_tau=<V_tau>` is equivalent to `V_tau` being a subgroup; pairwise commuting generators generate an abelian group; and positive-generator BFS suffices because the generated monoid in a finite group is the generated subgroup. These elementary implications still need Validator reconstruction.

## Success certificate

Stop at the first row having both observables `closure boundary = NONE` and `noncommuting pair != NONE`. Preserve:

- the exact tuple `tau`, a basis and multiplication table for `J_tau`, and `dim J_tau`;
- the complete `x -> x^3` manifest defining the actual value set, with deterministic hashes;
- the Cayley BFS list showing exact set equality `V_tau=<V_tau>`;
- two listed values `x^3,y^3` with their roots and the nonzero matrix difference `x^3y^3-y^3x^3`;
- the canonical constraint-and-conclusion matrix, including `p=3`, order `3^(dim J_tau)`, exponent exactly `9`, actual-value-set equality, subgroup closure, and nonabelianity.

That is a candidate `CLAIM`, not a certification; stop and route it to Validator.

## Failure certificate

For each of all eleven rows, preserve exactly one of:

- a direct boundary triple `u,b in V_tau` with `u circle b notin V_tau`, including cube roots and an exhaustive actual-value manifest; or
- exact set equality followed by the complete pairwise-commuting table for the generating list `B`.

If all eleven rows receive one of those certificates and none receives the success certificate, report `STRATEGY_EXHAUSTED` for `EQ11-CUBE-CAYLEY/E_12` only. Do not infer anything about the unequal-endpoint family, dimensions above `12`, other algebra groups, other primes, or the unrestricted target.

## Hard kill

No parameter broadening, third generator, Hall-span enlargement, split ansatz, endpoint-pair inference, or leading-additivity converse is allowed. Stop immediately on a target-equal candidate. Otherwise stop after all eleven exact row certificates. At active minute `59`, stop even if incomplete; name every unevaluated row and report only an incomplete-method outcome, never family exhaustion.

## Self-critique

The likeliest failure is that endpoint equality reflects a stronger low-dimensional commutativity phenomenon, or that every noncommutative cube image still fails closure. Even complete failure would exclude only eleven rows of one two-generator algebra-group template. The method also remains dependent on exact implementation; hashes and generated-subgroup size alone are not evidence unless the complete actual-value set equality and direct boundary witnesses are retained for independent reconstruction.
