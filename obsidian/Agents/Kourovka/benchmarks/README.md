# Benchmark run manifests

This directory contains public run metadata and frozen agent artifacts only. Read
`_meta/agents/Kourovka/benchmarking-kourovka.md` before creating a run.

Never store a private solution, shared-chat link containing it, secret generator,
seed, commitment salt, or hidden evaluator rubric here. Start from
`_meta/agents/Kourovka/templates/benchmark-run-template.json` and freeze the
manifest before the statement is released to agents.

The withheld Kourovka solution remains outside the vault and is one-shot. Do not
ask the human to reveal its problem number, solution, or link until the protocol
and output have been frozen.
