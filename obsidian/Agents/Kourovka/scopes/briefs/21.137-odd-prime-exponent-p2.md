# Active statement

Let (p>2) be prime and (G) a finite (p)-group of exponent exactly (p^2).
If the set (P=\{g^p:g\in G\}) of actual (p)-th powers is a subgroup, must
(P) be abelian?

# Non-negotiable exclusions

The exponent-8 two-group clause is a separate scope. A (p=2) example is out of
scope. A group of exponent other than exactly (p^2), or a check involving only
the generated verbal subgroup (G^p) without proving equality with the actual
power set, is also out of scope.

# Direction and first strategy

The planning estimate is 0.58 that the assertion is true, so this run starts in the
proof direction. Translate closure of the actual (p)-power set into exact
Hall--Petrescu/commutator identities and look for a bilinear, quadratic, Lie-ring,
or class-reduction formulation. Any candidate must be checked row-by-row against
the canonical constraints before it is treated as relevant.
