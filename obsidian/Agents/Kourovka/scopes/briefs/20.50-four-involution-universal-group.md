# Active statement

Determine the order of the largest group (G_4) generated by four involutions and
satisfying ((xy)^4=1) for every pair of involutions (x,y\in G_4).

# Scope trap

The relation ranges over all involutions in the group, not only over pairs of the
four chosen generators. A finite quotient or a group satisfying generator-pair
relations is not automatically the universal (G_4).

# Direction and first strategy

The planning estimate is 0.62 that the intended universal object is finite, so this
run starts in the proof/determination direction. First derive structural
consequences that apply to every group in the class and specify what would prove
universality. Use bounded quotient computation only after the target object and
certificate are explicit.
