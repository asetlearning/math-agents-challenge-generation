# Active statement

For a finite group (H), let (V(H)) be the set of orders of elements on which at
least one irreducible complex character of (H) vanishes. Determine whether every
finite group (G) and finite simple group (S) with
(|G|=|S|) and (V(G)=V(S)) must be isomorphic.

# Direction and first strategy

The planning estimate is 0.45 that the recognition assertion is true, so this run
starts in the counterexample direction. Design an order-matched nonsimple group
against a structurally new simple-group family and use exact character data. A
bounded table scan is useful only when it covers a named family and any collision
can be independently reconstructed.
