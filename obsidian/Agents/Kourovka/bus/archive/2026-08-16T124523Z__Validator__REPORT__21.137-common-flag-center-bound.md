# 21.137 common-flag verdict

**PASS as a structural partial; active scope unanswered.**

The image \(S\) of \(H\) on the class-2 Lie algebra \(L\) is a finite \(p\)-group, so it lowers one complete common flag. For every \(a\in Q\), root-surjectivity gives a root action \(A=I+N\) with

\[
N^p=A^p-I=D_a.
\]

Thus \(N^pF_p=0\) says \([F_p,a]=0\) for every \(a\in Q\), and

\[
F_p\le Z(Q),\qquad \dim_{\mathbf F_p}Z(Q)\ge p.
\]

The \(F_p\) indexing is legitimate: a noncentral \(a\) has \(D_a\ne0\), so \(N^p\ne0\) already forces \(\dim L\ge p+1\). The separate extraspecial argument is also correct, but is now redundant because an extraspecial \(Q\) has one-dimensional center.
