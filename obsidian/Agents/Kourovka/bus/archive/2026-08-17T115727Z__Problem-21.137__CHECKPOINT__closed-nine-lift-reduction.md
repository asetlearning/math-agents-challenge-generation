## Exact hand reduction after timeout

For an outer element `u`, write any lift over `u^-1`, in the fixed `(V,C,W)` column convention, as `A=I+N` with

```text
N = [ G   0   0 ]
    [ a   0   l ]
    [ T   0   H ] .
```

Here `G=g-I`, `H=h-I`, and the nine inner lifts vary only the row `a:V->C`. For a 3-subgroup image, `G^2=H^2=0`. Direct block multiplication gives

```text
N^3|_V = ( l(TG+HT) into C , HTG into W ),
```

with every other block zero. In particular `N^3` is independent of the inner-lift row `a`.

An admitted noncentral root must already have regular central restriction, equivalently `rank(H)=1` and `lH !=0`; then `im(H)=ker(H)` and `l` is nonzero on `ker(H)`. Put `r=l(TG+HT)`. The complete lift criterion collapses to

`HTG=0` and `r!=0`, with the unique cube label `abar` defined by

`r=(abar_2,-abar_1)`.

Indeed `HTG=0` gives `rG=0`, hence `N^4=0`; nonzero rank-one `N^3` on a five-space forces Jordan type `J4+J1`. The projected fixed-space condition is automatic and independent of `a`:

- if `G=0`, solvability in `W` gives projection `ker((lH)T)=ker(r)=<abar>`;
- if `rank(G)=1`, `im(G)=ker(G)=L`, and `HTG=0` gives `T(L)<=im(H)`, so the projection is `L`; also `rG=0` gives `L=ker(r)=<abar>`.

Adjustment by `ker(H)` always solves the remaining central equation because `l|ker(H)` is nonzero. Therefore, for every outer element and every nonzero `abar`,

`n_u(abar) in {0,9}`,

and exactly one `abar` has value 9 when the displayed criterion passes. No nine-element inner loop, rank sequence, or fixed-space calculation is needed.

Consequently the max flow is just a histogram. If `m_abar` is the number of outer elements assigned to `abar` and `k=81/|U|`, then

`maxflow = sum_(abar!=0) min(27, 9k*m_abar)`.

This is conjugacy-invariant up to the natural permutation of the eight labels. It strengthens the `PROFILE-BEFORE-FUSION` pivot and makes it a small `2x2` element scan per retained Sylow class. It is still only the factor-independent necessary gate; no quotient type is yet eliminated.
