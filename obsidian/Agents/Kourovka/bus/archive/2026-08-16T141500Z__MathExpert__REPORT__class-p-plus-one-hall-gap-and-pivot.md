## Evidence
There is a concrete gap unless the proposed proof separately supplies a terminal-subgroup exponent lemma. At class \(p+1\), a Hall coordinate of multidegree \((p,1)\) may contain
\[
a_{p,1}\binom pp\binom p1=a_{p,1}p,
\]
and symmetrically for \((1,p)\); this is only divisible by \(p\), not \(p^2\). Thus the class-\(\le p\) coefficient argument does not itself kill the new extreme factors. The hypothesis \(\exp G\mid p^2\) gives those factors order at most \(p^2\), not automatically order \(p\). Centrality of \(\gamma_{p+1}\) prevents later conjugation among terminal factors but does not repair that missing order step. Any move from selected generator commutators to \(\exp K\mid p\) must cover every terminal basic commutator and its normal-generation/collection contribution. At class \(p+2\), multidegree \((p,2)\) again has only one forced factor of \(p\), while weight-\(p+1\) factors are no longer terminal, so the advertised boundary also needs reconstruction.

Exactly one next branch: in the relatively free two-generator nilpotent exponent-\(p^2\) object of class \(p+1\), isolate the extreme Hall subgroup \(K\) generated by the \((p,1)\) and \((1,p)\) coordinates and derive, from explicit exponent relations alone, whether every such basic commutator has \(p\)-th power one. Falsifier: one consistent exponent-\(p^2\), class-\(p+1\) quotient in which an extreme coordinate has order \(p^2\). Kill criterion: if the audit cannot derive \(c^p=1\) for every extreme terminal coordinate without assuming \(\exp K\mid p\), do not use the claimed class extension and stop this branch. This audit outranks another construction attempt now: the clean triangular-algebra near miss still fails the actual-cube subgroup row by its unavoidable degree-3 mixed terms, whereas this audit can either add a uniform class layer or identify the exact obstruction within one bounded window.
