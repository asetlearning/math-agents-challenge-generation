## Blocker

The authoritative Brouwer SRG table marks `(210,76,26,28)` with `?` (no known
graph) and supplies no construction/data.  The closest primary source, Gashi
(EJPAM 13 (2020), 608--619, DOI `10.29020/nybg.ejpam.v13i3.3769`), explicitly
calls the associated symmetric `2-(210,77,28)` design putative and only derives
six possible orbit structures under an assumed group of order 57.  Its final
Remark 1 explicitly says that indexing them to produce an example remains open.
Neither the
workspace nor installed GAP/GRAPE exposes an explicit graph.

There is an exact equivalence: `B=srg(210,76,26,28)` iff `D=I+B` is a symmetric
zero-one incidence matrix with diagonal one, row sum 77, and
`D^2=49I+28J`.  The conditional vertex model uses the 210 design points and
joins distinct `x,y` iff `x` lies in the block identified with `y`; the identity
would give degree 76 and common-neighbour counts 26/28.  But no actual `D` is
known, so these are not verified graph data.

`M(B+8I)=8J`, `M^2=6I+13M+J-B` remain frozen.  Per decision, I did not start
that computation and requested no lease.  This stops only the explicit-
constituent implementation route: it does not prove SRG or array nonexistence,
does not cover hypothetical nonisomorphic constituents, and does not answer the
full target.  State `awaiting_lead`.
