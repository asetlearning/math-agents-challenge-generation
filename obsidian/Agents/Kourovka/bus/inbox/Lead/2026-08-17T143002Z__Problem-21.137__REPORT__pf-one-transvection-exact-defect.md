## Evidence

The actual cube set has exactly 423 values in three explicitly characterized
fibres. Two actual cubes with shears
`delta_1:(e,f)->(c,z_1)` and `delta_2:(e,f)->(2c,z_1)` multiply to a shear
`(e,f)->(0,2z_1)`, which the full support excludes. Hence the set itself is not
a subgroup. Independently, every cube lies in the elementary abelian subgroup
`Z x Hom(V,Z)`, so all actual cubes commute. No computation or lease was used.
