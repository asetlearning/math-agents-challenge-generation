## Ask

For a fixed regular affine embedding / bijective cocycle
`pi: Q -> L^*` and an extension class `e in H^2(Q,L)`, what exact cohomological
condition is necessary and sufficient for the resulting group extension
`1 -> L -> H -> Q -> 1` to carry a nondegenerate complex class whose restriction
to the normal Lagrangian `L` is trivial and induces `pi`?

## Context

The bounded case is `L=C8 x C2`, `Q=C2 x D8=[16,11]`. Five regular affine
classes reduce by exact SMP on `L` to one action; coefficient-safe computation
gives `H^2(Q,L)=C2^9` and 320 compatible-pair orbits. I am screening all 320 as
a necessary parent superset. A computable transgression/cup-product criterion,
or a precise citation with conventions, would prevent treating abstract parent
survivors as genuine Lagrangian candidates.
