# T-028 A_R r11: review

This is a Lead request (2026-10-21). The proposal is `MathExpert/proposals/2026-10-21-t028-ar-r11-proposal.md`. Triage: [[2026-10-21-t028-ar-r11-review-triage]]. The method is argument and arithmetic only, with no runs.

**Terms** (as in the proposal):
- **N:** the short-run normal form. It repeatedly rewrites u^k → u^{k−5·sign k} for primitive u with |u| ≤ 2 and |k| ≥ 3, taking the leftmost run first.
- **(ii-local):** the window-by-window version of (ii). Each difference window α_j against β_j is proved equal by kbmag.
- **Recovery:** a break that meets the nondegeneracy rule. Every other break is "kbmag-dominated".

## 1. N, the short-run normal form

**Sound (argued).**
- Each rewrite multiplies by a conjugate of u^{∓5}.
- If the run wraps around the cyclic word, the rewrite is a conjugacy, not an equality: N(z) is conjugate to z·∏cells.
- That is enough, because only "= 1" is carried through the argument.
- The cores must be logged literally as u^{±5}, the same check as for the R cells.

**It terminates.** For |k| ≥ 3 we have |k − 5| < |k|, so every rewrite shortens the word by at least |u|.

**Well defined only with a base point.** "Leftmost" has no meaning on a cyclic word.
- **Pin:** fix the starting rotation, for example the cyclically reduced linear word as given, and fix how a run across the wrap point is treated.
- With that fixed, N is a deterministic function.

**N is not confluent.**
- On the toy word a a a b a b a b (8 letters):
  - leftmost first: a³ → A², which gives A A b a b a b (7 letters). Its b a b a b is (ba)^{2.5}, not a cube, so N stops;
  - (ab)³ first: a a B A B A (6 letters), which has no further run.
- The two orders give different words of different lengths.
- This does not affect soundness, since both are trivial-preserving. It does mean N(w) and N(φ′(context)) can differ by more than junction effects, because of the strategy alone. That bears on open question 1, which should be measured as the proposal says.

**N against R.** For |u| ≤ 2, R's rewrite can only fire at integer k ≥ 3: a period-2 run of length 5 has exponent 2.5 and score 0 under the canonical tie-break.
- So N and R apply the same rewrite rule and differ only in order. That supports the conjecture of §1a.
- This is argued from the score formula. I did not check whether R ever applies a score-0 rewrite.

**"N(φ′(a_{i−1}a_i a_{i+1})) restricted to the a_i window" is undefined** once N cancels across block boundaries.
- **Pin:** give a provenance rule, for example letters keep the index of their source block, and a rewritten run is assigned to the block holding its start.
- It only proposes candidates, so this is about reproducibility, not soundness.

## 2. (ii-local)

**Sound (argued), provided the decomposition is checked literally.**
- **Pin:** the implementation checks, letter by letter, that N(w) = c₀α₁c₁…α_n c_n and N(z°) = c₀β₁c₁…β_n c_n, each after one fixed rotation (a conjugation, which is harmless). An empty α_j or β_j is allowed.
- Then:
  - each loop α_jβ_j⁻¹ reduced to IdWord gives α_j = β_j in G₇;
  - substituting gives N(w) = N(z°) in B;
  - N(z°) is conjugate to z°·∏cells, z° is conjugate to φ′(t′), and φ′(t′) = 1 by (i).
- So w = 1 in B.
- kbmag on a rotation of a loop is also valid, since a rotation is a conjugate.

**Budget.**
- Up to 10 CPU-s per loop over n windows has no bound.
- **Pin:** a cap on the number of windows, or on the total (ii-local) time, inside A_R's 15 CPU-min. A run that hits the cap is "candidate kbmag failed", not a break.

**Attribution.** Measuring the windows and not |Δ| is right: it charges the difference d, not its conjugator p.
- **Gap:** nothing bounds the block length against |w|, and nothing sets a minimum token count for t′. A blind pair with long blocks lets one window reach 3·max(|x′|, |y′|), up to |N(w)|/4. Proving that window is then a kbmag job on a quarter of the word.
- **Pin:** one more condition, set on the tune set before the freeze. For example, max(|x′|, |y′|) ≤ |w|/8, or |t′| ≥ 8 tokens.
- **Write down the baseline that justifies the word "recovery":** an archived survivor passed S1-each's KB on 16 images, so kbmag alone failed on w. A proof by short windows is therefore added value. (This depends on Lead's G1 decision on what KB resilience means in S1-each.)

## 3. Control design

**Issue 1: the strata cannot be populated.**
- The control residuals are "full-R residuals", but the pass line is per chain-composition stratum (R-only, contains KB, contains D).
- R alone yields only R-only residuals. "Contains KB" and "contains D" would be empty, so r11 could neither pass nor fail there.
- **Fix, one of:**
  - the control residuals run through the pilot's own screen chain (R → KB → D, with the same caps and the canonical R);
  - or the pass line is restated for R-only, with the other strata "not assessed", which leaves them "attack-limited".

**Arithmetic.**
- 30 × (3 + 15) min = 9 CPU-h.
- The depth series is 10 W × 6 depths × 3 min = 3 CPU-h.
- The ceiling is therefore 12 CPU-h, as stated.
- **Expected cost:** with the Developer's measured 2.5–4 CPU-min for a failing blind run, plus oracle runs at up to 3 min, it comes to about 3–5 CPU-h. **The 4 CPU-h pause will probably fire.**
- **Pin:** run blind on the 30 control W first, then oracle, then the depth series. Otherwise a pause can leave the pass-line mode incomplete. Alternatively, raise the pause via Lead.

**Small n per stratum.**
- 30 words over 3 strata gives n ≈ 10 per stratum. At 5/10, the Wilson 95 % interval is about [0.24, 0.76].
- **Pin:**
  - the rule uses the point estimate (r10's convention), with the intervals reported beside it;
  - a stratum with n < 10 is "not assessed", and its failures stay "attack-limited".

**Other points.**
- **Only recoveries count.** That is stricter than r10, where breaks count. It is fine as declared, but r10 and r11 rates are then not comparable, and the report should say so.
- **The oracle diagnostic below 80 % on R-only** is a good separate test of the tolerance and verification model.
- **The seed label "20261021|arctl|m|index"** is fresh, and contains no arm, so it cannot collide with a pilot label. The clash check (against tune W and pilot W) must include the CTRL cells and use the first 30 non-degenerate indices (see the job-1 addendum).
- **κ's extrapolation.** κ is calibrated at m ∈ {8, 16} and applied at m ∈ {6, 12, 24}. At m = 6, ⌈κℓ⌉ + 1 can exceed the information cap quickly. The "unusable at that m" clause covers only the tune set's m. **Suggest:** if the cap binds at m = 6, apply the same rule there.
- **Consistency nit:** §0 says oracle mode "recovers 0/18", while the handoff says oracle mode gave 2/18 breaks. Write "2 breaks, both kbmag-dominated, 0 recoveries", if that is what happened.

## 4. Leakage

**Issue 2a: freeze timing.**
- r11 is applied to job 1's archived survivors.
- Suppose κ, the window bounds or the beam are set after anyone has read job 1's A_R (r10) traces or failure statistics. That is tuning on survivors by the back door.
- **Pin:** freeze r11 (repo@sha and every number recorded) before any job-1 A_R output is read, and state in the note that no job-1 artifact informed any r11 number.
- If that ordering cannot be kept, Lead must decide whether r11 verdicts on job-1 survivors count.

**Issue 2b: the calibration word.**
- §0 builds r11's tolerance model from the 849-letter calibration residual (83 short cells; 181 edits over 53 blocks).
- Its W is the pilot label C1|16|0, which job 1 draws again.
- **Pin:** if that word, or the second calibration survivor, is among the archived survivors, its "A_R r11" verdict is labelled **"tuned on"**. The proposal currently excludes it only from the control rates.

**Code paths.**
- `ar_control.depth_items` defaults to pilot words (`tune=False`). r11's depth series must use the arctl label, and its calibration must use the tune label.
- Code support for the new label is needed.

**Otherwise clean.**
- Blind mode reads only w, R7 and the kbmag systems.
- Oracle mode gives no survivor verdict.
- There is no feedback into generation.

## Verdict

- **CONFIRMED on soundness.** N and (ii-local) prove w = 1 in B (argued), given the literal decomposition check and literal cores.
- **Fix before the freeze:**
  - issue 1, the control strata;
  - issue 2, freeze timing and the "tuned on" label.
- **Pins:**
  - N's base point and strategy;
  - the provenance rule;
  - the (ii-local) time cap;
  - an extra attribution bound;
  - minimum n per stratum, with the rule on the point estimate;
  - the run order before the pause;
  - the 0/18 wording.
- None of these needs a further mathematical judgement once written in.
