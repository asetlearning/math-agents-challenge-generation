# T-028 Phase 0b review

Triage: [[2026-10-23-t028-phase0b-nonnilpotent-review-triage]]. Source: Experimenter-B25 `t028-phase0/` (`pairs.g`, `lowindex.g`, `relwords.g`, logs). G_7 = <a,b | v^5, |v| <= 7>. Witness = finite quotient of G_7 of order not a power of 5.

## Verdict
1. **Pair search equals GQuotients on the targets: CONFIRMED.** Any image of G_7 in H is generated by two elements of order 1 or 5. An order-1 image gives a cyclic 5-group, so it is never a witness. So it suffices to take x over H-class representatives of order-5 elements and y over all of them: this covers every pair up to H-conjugacy, and every subgroup of H, not only onto H. No Aut issue arises: the search uses all pairs, which is more than the Aut(H)-classes that GQuotients returns. Cross-check with my own code (all freely reduced words, `MappedWord`, no canonical-class machinery): onto H = A5, A6, A7, PSL(2,11), PSL(2,16) and K = 2..4, GQuotients and the Aut(H)-orbit count of generating pairs of profile >= K agree (A6 at K=2: 2 and 2; PSL(2,11) at K=2: 1 and 1; all other cells 0 and 0).
2. **maxL logic: CONFIRMED.** Words are sorted by length, so the first failing word gives L = length - 1. A canonical primitive class representative covers all its rotations, inverses and powers (v^5 = 1 for a conjugate or power follows). The `L>=maxL` shortcut only skips pairs that cannot raise the maximum, and the 5-group filter is correct. My independent run (freely reduced words up to length 7, x over all elements for A5..A7, class reps elsewhere) reproduces every maxL in the table: A5 1; A6..A10 2; Sz(8) 2; PSU(3,4) 3; PGammaL(2,32) 2; the 18 PSL(2,q) cases 1-2 (same values per q), 0 pairs with L >= 7. The 18 q is the complete set of prime powers <= 89 with 5 | q(q^2-1).
3. **Weak spot: the positive control.** K=2 has 4 relators, so it does not exercise long words. The GQuotients cross-check above (K=3,4, with the A6 and PSL(2,11) hits at K=2) is the stronger control. Suggest adding it to the note.
4. **Low index.** "7 subgroups" at N=12 and N=20 means G itself plus six subgroups of index 5. So G_7 has no subgroup of index 2..4 or 6..20, a stronger statement than "the coset images are 5-groups". N=30 timed out and decides nothing.

## Scope (what the result does not support)
Take a minimal-order quotient Q of G_7 that is not a 5-group. It has a unique minimal normal subgroup N, and Q/N is a 5-group. Two cases:
- **N nonabelian, N = S^k.** The listed H cover only k = 1, S in {A5..A10, Sz(8), PSU(3,4), PSL(2,q) for q <= 89, PSL(2,32) with its order-5 field automorphism}. Not covered: any other S (PSL(3,4), PSL(2,q) with q > 89, A_n for n >= 11, sporadics such as J1, ...), k >= 2, and PSL(2,243) = PSL(2,3^5) with field automorphisms.
- **N = F_p^k, p != 5.** Then Q = N x| P with P a 5-group quotient of G_7. Such a Q exists iff, for a normal subgroup K of 5-power index, K^ab has a non-5 part (a free summand or p-torsion). Low index <= 20 sees only P = C5 or C5^2 acting on N of small degree. I probed this directly: R_c = kernel of G_7 -> (lower exponent-5 class-c quotient). `AbelianInvariants(R_c)` = 5^6 (c=1, index 25), 5^12 (c=2, index 125), 5^14 (c=3, index 3125), with no non-5 part. If a subgroup K has a quotient C_p (p != 5) and K contains R_c, then R_c does as well (the index [K : R_c] is a 5-power). So no solvable witness of that type has P of class <= 3. The class <= 12 cases (P up to 5^34) are not decided. Local run: GAP 4.15.1, capjob 2G / 2 CPUs, 481 s for c=3.
